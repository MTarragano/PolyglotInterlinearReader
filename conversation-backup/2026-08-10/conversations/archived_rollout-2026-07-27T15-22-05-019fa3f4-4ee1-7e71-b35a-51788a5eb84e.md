Sites supplies managed deployment, version history, access control, analytics, secrets, custom domains where available, a relational database called D1, and R2 file storage. You do not administer a server. Conversely, you cannot install PHP, Python services, MySQL, background workers or arbitrary Linux software. - Use Sites now for a private, live version of the current reader prototype.

- Sites is currently a public beta with plan-specific limits rather than conventional usage pricing.
- Every deployed URL is production; versions can be saved without deployment for review.
- New Sites default to restricted access and can later be shared or made public.
- Private networks and some databases/frameworks/background services are unsupported.
- Data residency is not supported at launch. [OpenAI’s current limitations and access guidance](https://help.openai.com/en/articles/20001339-creating-and-managing-chatgpt-sites)
