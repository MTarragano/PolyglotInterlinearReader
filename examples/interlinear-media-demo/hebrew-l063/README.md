# Hebrew Lesson 63 Reader-trial package

This is a provisional Reader document derived from the local Lesson 63 portion
of the LWT HTML export and its local MP3. The source text came from the local
file; transliteration, roots, morphology, glosses, English meanings, and
sentence translations are Codex-generated candidates pending parser,
dictionary, and human comparison.

The deliberately broad `translations` arrays support the trial requirement to
show multiple meanings associated with an undotted Hebrew spelling. They must
not be mistaken for verified exhaustive dictionary entries.
